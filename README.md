## Présentation

TourShop est une page d'accueil de boutique en ligne écrite entièrement à la main, pour maîtriser les fondamentaux du front-end : structure sémantique, mise en page responsive en CSS natif et interactions en JavaScript.

## Fonctionnalités

- Carrousel d'accueil plein écran avec **Swiper.js**
- Menu de navigation mobile (ouverture et fermeture en JavaScript)
- Sections *Home*, *Shop* et *Deals* avec navigation par ancres
- Mise en page responsive, du mobile au desktop
- Images optimisées aux formats modernes (AVIF, WebP)

## Lancer le site

Aucune installation n'est nécessaire :

```bash
git clone https://github.com/Russel-Kamgang/Site-Web-Ecommerce.git
cd Site-Web-Ecommerce
# Ouvrir index.html dans le navigateur, ou servir le dossier :
npx serve .
```
